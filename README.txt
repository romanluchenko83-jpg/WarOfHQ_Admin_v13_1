ВОЙНА ФРАКЦИЙ — v13

V13
- Весь JavaScript приведён к единому стилю, ориентированному на Google JavaScript Style Guide: 2 пробела, пробелы вокруг операторов, фигурные скобки у управляющих конструкций, единообразные переносы и финальная новая строка.
- Добавлен .editorconfig для сохранения этого стиля в редакторах.
- Кулдаун «Абсолютного щита» уменьшен с 18 до 13 секунд.

ЗАПУСК
1. Распакуйте архив.
2. Откройте index.html в современном браузере.
3. При ограничениях локальных файлов используйте start_server.bat / start_server.sh и откройте http://localhost:8080.

V10
- После входа игра всегда открывает Главную со статами, а не экран боя.
- Бои за разные земли теперь независимы и могут продолжаться параллельно.
- Выход из боя окончательно освобождает игрока от этой битвы; вернуться туда можно только платным перезаходом.
- После выхода игрок может сразу записаться в другую землю. Если её бой уже идёт и есть место, вход происходит сразу.
- Одновременно находиться или быть записанным в нескольких битвах нельзя.
- При записи в будущую битву игра автоматически открывает бой при наступлении таймера, если игрок находится в разделе земель.
- Карта земель получила отдельные иллюстрации локаций: снежная крепость, лес, шахта, центральная цитадель, долина и болота.
- Центральная цитадель отображается крупнее в центре карты.

УПРАВЛЕНИЕ БОЕМ
Space — выбрать базовый удар.
1–5 — способности роли.
Q — свой штаб.
E — вражеский штаб.
